# Contributing

Read [AGENTS.md](AGENTS.md) first — it is the contributor contract for this
repository: English prose, one contributor identity, no vendored instrument
trees, no operator or engagement details, and the public-tree language
policy.

The `engine/` tree is a one-way export from its source tree: engine changes
are made upstream and re-exported, so do not send engine pull requests here.

Bug reports and documentation fixes are welcome as issues. Security reports
go through the private channel in [SECURITY.md](SECURITY.md). Because every
commit must carry the repository owner's GitHub-linked identity, code
contributions are by arrangement — open an issue describing the change before
starting work.
